DESIGNED & BUILT BY JASON KIM

From spreadsheets to a working system.

A practical project for a property rental business.

The original problem

Charges were entered in Excel, exported to PDF, emailed, then saved to Google Drive. The client wanted to look up records and send invoices without being at a particular PC.

The application

I connected properties and leases with billing, payment history, document storage and invoice delivery using Python, Django, PostgreSQL and Docker.

What needed care

Corrections must retain payment history. Cancellations must keep their original records. Access depends on roles and properties. Backups need to be tested by restoring them.

Working within limits

The application runs on a NAS. I worked on reducing repeated queries, limiting expensive simultaneous jobs and controlling memory use.

About this demonstration

This is a browser-only adaptation of selected workflows, not the live Django application. Data is fictional and changes stay in local browser storage. It does not demonstrate server authorization, email delivery or NAS performance.
